# 🎬 Sentiment Analysis on IMDB Dataset

## 📌 Overview
This project is an end-to-end Machine Learning system that classifies movie reviews as **positive** or **negative** using real-world data from the IMDB dataset (50,000 reviews).

The project demonstrates how to build, train, and evaluate a text classification model using Natural Language Processing (NLP) techniques.

---

## 🧠 Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Logistic Regression

---

## ⚙️ Features
- Data loading and preprocessing
- Text vectorization using TF-IDF
- Model training using Logistic Regression
- Model evaluation using accuracy and classification metrics
- Interactive system for predicting sentiment on new user input

---

## 📥 Dataset Download
The dataset is not included in this repository due to size limitations.

## 📊 Dataset Information
- Size: 50,000 movie reviews
- Labels: Positive / Negative

---

## 📈 Model Performance
The model was trained and evaluated using a train-test split approach and achieved approximately:

- **Accuracy: ~88%**

## 🔄 Machine Learning Pipeline
This project follows a complete machine learning workflow:

1. Data loading  
2. Data preprocessing  
3. Feature extraction (TF-IDF)  
4. Model training  
5. Model evaluation  
6. Prediction on new input
